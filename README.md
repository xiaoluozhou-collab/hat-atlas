# 小叶子的全球帽子分析图鉴

全球 **51 家** 设计师与手作帽饰品牌图鉴（按 A–Z 排序），严格收录有图帽款，支持按**销量 / 热度 / 艺术性**三维排序与排行榜对比，并附各品牌购买途径。

- **在线访问**：https://xiaoluozhou-collab.github.io/hat-atlas/
- **定时更新**：通过 GitHub Actions（[`.github/workflows/weekly-update.yml`](.github/workflows/weekly-update.yml)）在**每周日北京时间 10:00** 自动同步品牌官网上新并巡检图片链接。
